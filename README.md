# Explainable-AI-for-Signature-Forgery-Detection
Developed an Explainable AI-based Signature Forgery Detection system using **Deep Learning (ResNet50)** to automatically classify handwritten signatures as genuine or forged. Implemented **Transfer Learning** to improve signature classification and integrated **Grad-CAM and LIME** to highlight important image regions influencing the model's predictions, making the detection process more transparent and interpretable. Evaluated the model using accuracy, precision, recall, F1-score, confusion matrix, and ROC-AUC.
